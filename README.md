# attendX - Facial Recognition Access Management System

A lightweight, face-recognition-based access management system designed to monitor attendance and enhance security in sensitive areas. Built as a third-year Computer Science Engineering capstone mini-project.

## Key Features
* **Facial Recognition Access:** Real-time identification using optimized computer vision models.
* **Analytics & Tracking:** Built-in dashboard to view presence statistics, access logs, and track individuals over time.
* **User-Friendly Desktop Interface:** Clean UI built with PySide6 for smooth user interaction and administrative control.
* **Scalable Data Store:** Currently powered by SQLite for rapid local testing, with schema modularity designed for easy database migration.

## Tech Stack
* **GUI:** PySide6 (Qt for Python)
* **Backend / Database:** Python, SQLite
* **Computer Vision:** Optimized Face Recognition Models
